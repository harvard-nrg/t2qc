# T2 Quality Control
T2QC is an automated quality control pipeline for T2-weighted (with or 
without volumetric navigators) MRI scans. T2QC is built on top of the 
excellent [`MRIQC`](https://mriqc.readthedocs.io/en/stable/) 
and [`vNav`](https://github.com/harvard-nrg/vnav) packages.

For the latest documentation please head over to [t2qc.readthedocs.io](https://t2qc.readthedocs.io).
